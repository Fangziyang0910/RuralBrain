## 三、文档格式要求

### 3.1 推荐格式

| 格式 | 推荐度 | 说明 |
|------|--------|------|
| Markdown | ⭐⭐⭐⭐⭐ | 最佳，结构清晰，易于切片 |
| PDF（文字版） | ⭐⭐⭐⭐ | 可接受，需要好的解析器 |
| Word/DOCX | ⭐⭐⭐ | 可用，但结构可能不清晰 |
| PPT/PPTX | ⭐⭐ | 不推荐，切片质量难以保证 |

### 3.2 文档命名规范

```
{类型}_{地区/主题}_{年份}.md

示例：
- policy_guangdong_2026.md
- case_rural_tourism_zhejiang.md
- policy_sichuan_implementation.md
```

### 3.3 元数据标注

每个文档应包含头部元数据：

```markdown
# 文档标题

> **类型**：policy / case / guide / tech
> **地区**：省份/城市/县区
> **年份**：2026
> **主题**：乡村振兴、乡村旅游、特色农业...
> **来源**：官方来源链接
```
