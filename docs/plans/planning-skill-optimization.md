# 规划技能产品定位分析与优化方案

> **文档状态**：草案
> **创建日期**：2026-03-11
> **核心问题**：规划技能的产品定位、知识库建设方向、差异化竞争策略

---

## 一、核心问题诊断

### 1.1 当前知识库现状（致命问题）

| 维度 | 现状 | 问题 |
|------|------|------|
| 文档数量 | **仅 2 个** | 完全无法支撑"规划咨询"定位 |
| 地区覆盖 | 仅广东部分地区（博罗县长宁镇） | 其他地区用户几乎无价值 |
| 内容类型 | 1 个案例 + 1 个旅游业政策 | 与"乡村发展规划"定位严重错位 |

**现有文档详情**：

| 文档名称 | 类型 | 地区 | 内容 |
|---------|------|------|------|
| 罗浮-长宁战略研究.pptx | 案例 | 广东博罗县 | 山镇融合发展战略（71页） |
| 广州市旅游业发展政策.docx | 政策 | 广州市 | 旅游业政策汇编 |

**结论**：当前系统存在"定位宏大、内容空洞"的根本性问题。

### 1.2 技能定位与实际内容对比

**当前定位声明**（来自 `planning.yaml`）：

```yaml
description: 规划咨询专家，查询乡村发展、政策、产业规划等知识库信息

核心能力:
- 乡村发展规划：产业发展规划、旅游规划、美丽乡村建设规划
- 政策解读：一村一品、乡村振兴战略、现代农业支持政策
- 治理模式：合作社模式、村企联建、党群共建等参考案例
- 技术指导：病虫害防治方案、种植养殖技术、农业技术支持
```

**知识库实际支持**：

| 声称能力 | 知识库支持 |
|---------|-----------|
| 乡村发展规划 | 仅有一个长宁镇案例 |
| 一村一品政策 | 无相关内容 |
| 乡村振兴战略 | 无相关内容 |
| 合作社模式案例 | 无相关内容 |
| 病虫害防治方案 | 无相关内容 |
| 种植养殖技术 | 无相关内容 |

## 二、用户需求分析

### 2.1 真实用户画像与问题类型

| 用户角色 | 典型问题 | 需要的信息 |
|---------|---------|-----------|
| 村干部 | "我们村想发展乡村旅游，有什么政策支持？" | 本地政策 + 成功案例参考 |
| 乡镇规划人员 | "建设美丽乡村有哪些成功模式？" | 模式分类 + 案例 + 实施要点 |
| 农业企业 | "搞一村一品，需要哪些条件？怎么做？" | 政策条件 + 申请流程 + 案例参考 |
| 投资人 | "这个地区的农业投资有什么政策优惠？" | 地方政策 + 产业规划 |

### 2.2 关键洞察

1. **用户大概率会问自己所在地的问题**
   - 需要地方政策支持
   - 需要相似地区的案例参考

2. **用户问题通常具体到某个村子或乡镇**
   - 知识库难以覆盖所有村庄
   - 需要处理"知识库中没有该地点"的情况

3. **用户可能不完全清楚自己需要什么**
   - 需要 Agent 引导式提问
   - 需要提供结构化的决策框架

## 三、核心问题解答

### Q1: 如果问的地方知识库没有，怎么办？

**三种策略对比**：

| 策略 | 实现方式 | 优势 | 劣势 |
|------|---------|------|------|
| **A. 用户提供信息** | Agent 主动询问："请介绍一下贵村的基本情况..." | 交互自然、信息准确 | 用户负担重 |
| **B. 通用框架 + 类似案例** | 先给通用方法论，再引用相似地区的案例 | 用户负担轻 | 可能不够贴合 |
| **C. 混合模式（推荐）** | 先用通用框架回答，再追问用户具体情况以补充 | 兼顾效率和针对性 | 实现复杂 |

**推荐实现流程**：

```
用户: "我们村想发展乡村旅游"

Agent:
1. 先从知识库检索"乡村旅游"相关的通用框架和案例
2. 给出初步建议框架
3. 追问："请问您村子在哪个省份？有什么特色资源？"
4. 根据用户补充，进一步细化建议
```

### Q2: 其他地点的知识库能否起作用？

**可以，但作用有限。需要设计"相似案例检索"机制**：

| 场景 | 作用 | 条件 |
|------|------|------|
| 相似资源禀赋 | 很有帮助 | 都是山区/都是平原/都有某种特色 |
| 相似发展模式 | 有参考价值 | 都想做旅游/都想做特色农业 |
| 完全不相关 | 几乎无价值 | 北方干旱山区 vs 南方水乡 |

**建议的相似案例检索策略**：

```
用户说：湖南山区某村想发展民宿

检索策略：
1. 从知识库找"山区民宿"相关案例（不管地点）
2. 找"湖南"或"华中地区"的政策支持
3. 返回：案例 + 通用方法论 + 政策依据
```

### Q3: 如何处理散乱的非结构化信息？

**不建议整理成知识图谱**（成本太高、维护困难）。

**推荐方案一：智能切片 + 元数据标注**

```python
# 文档入库时自动提取元数据
{
    "doc_id": "case_001",
    "location": "广东省博罗县长宁镇",      # 自动提取地点
    "themes": ["乡村旅游", "产业发展"],     # 自动提取主题
    "resource_type": ["山区", "温泉"],      # 资源类型标签
    "success_factors": [...],              # 关键成功因素
    "applicable_regions": ["华南地区"]      # 适用范围
}
```

**推荐方案二：检索后智能聚合**

```python
# 检索时不是简单返回片段，而是：
1. 检索多个相关片段
2. LLM 聚合生成"案例模式总结"
3. 输出时引用原始来源
```

### Q4: 是否需要在回答旁标注来源？

**强烈建议实现。这是与通用大模型的核心差异之一。**

**当前系统已支持基础来源标注**：

```
【知识片段 1】
来源: 0524-罗浮长宁战略研究.pptx
位置: 第10页
相似度: 0.856

内容: 长宁镇是"两圈两区"交汇之地...
```

**建议增强为**：

```markdown
## 核心建议

### 1. 确定核心产业定位
建议结合当地资源禀赋，选择1-2个主导产业...
> 📚 参考：罗浮-长宁战略研究（第10页）

### 2. 建立产业融合机制
...
> 📚 参考：广州市旅游业发展政策（第二章第三节）

---

## 📖 引用来源
- [1] 罗浮-长宁战略研究 - 第10页、第15页
- [2] 广州市旅游业发展政策 - 第二章
```

### Q5: 如何与通用大模型区分？

**核心差异化策略**：

| 维度 | 通用大模型 | 规划技能应做到 |
|------|-----------|---------------|
| 回答来源 | 模糊的"基于我的知识" | **明确标注引用来源、页码** |
| 案例引用 | "某地做了什么"（可能编造） | **真实案例+原始文档链接** |
| 政策引用 | 可能有幻觉 | **准确引用政策原文+出处** |
| 本地化 | 通用建议 | **结合地方政策+本地资源分析** |
| 可追溯 | 无法验证 | **点击来源可跳转原文** |

**示例回答格式（知识库中无该地点时）**：

```
针对乡村旅游发展，我提供一个通用框架：

## 通用发展路径（基于多个成功案例总结）

1. 资源评估：盘点自然/文化/产业资源
2. 市场定位：确定目标客群
3. 产品设计：开发特色体验项目
...

## 类似案例参考

虽然知识库中没有您所在地区的案例，但以下案例可参考：

📌 **广东长宁镇案例**（山区+旅游型）
- 特色：依托罗浮山发展康养旅游
- 成功要素：高铁站+文化资源+产业规划
- 📖 详情：点击查看完整案例

📌 **广州乡村旅游政策支持**
- 补贴标准：...
- 申请条件：...
- 📖 详情：政策原文

---

💡 **补充说明**：如需更针对性的建议，请告诉我：
- 您所在省份/地市
- 村庄的主要资源特色
- 当前产业发展情况
```

## 四、优化实施方案

### 4.1 短期方案（快速见效）

#### 4.1.1 明确产品定位边界

**当前定位**：
```
"规划咨询专家，查询乡村发展、政策、产业规划等知识库信息"
```

**建议修改为**：
```
"乡村规划案例与政策参考助手，基于知识库提供乡村发展规划案例参考和政策查询服务"
```

**关键变化**：
- 诚实告知能力边界
- 聚焦"案例参考"和"政策查询"
- 避免过度承诺

#### 4.1.2 优化回答模板

1. **强制引用来源**
   - 所有知识库内容必须标注出处
   - 区分"知识库内容"和"通用建议"

2. **无匹配案例时的处理**
   - 主动追问用户信息
   - 提供相似案例作为参考
   - 给出通用框架

3. **回答结构标准化**
   ```markdown
   ## 核心建议
   （基于知识库 + 通用知识）

   ## 📖 引用来源
   （知识库文档列表）

   ## 💡 补充信息
   （如需更针对性建议，请提供...）
   ```

### 4.2 中期方案（核心建设）

#### 4.2.1 知识库内容扩充（最重要）

**优先级排序**：

| 优先级 | 内容类型 | 来源建议 | 预期价值 |
|--------|---------|---------|---------|
| P0 | 国家级乡村振兴政策 | 中央一号文件、乡村振兴战略规划 | 高，适用全国 |
| P0 | 分省乡村振兴政策 | 各省政府官网、农业农村厅 | 高，地方特色 |
| P1 | 典型案例（按产业类型） | 农业农村部典型案例、学术论文 | 高，可借鉴 |
| P1 | 典型案例（按地区） | 地方政府公开报告 | 中，相似性参考 |
| P2 | 农业技术指导 | 农技推广站、农业院校 | 中，专业指导 |
| P2 | 乡村治理模式 | 组织部案例、党校案例 | 中，治理参考 |

**文档格式建议**：

| 格式 | 推荐度 | 说明 |
|------|--------|------|
| Markdown | ⭐⭐⭐⭐⭐ | 最佳，结构清晰，易于切片 |
| PDF（文字版） | ⭐⭐⭐⭐ | 可接受，需要好的解析器 |
| Word/DOCX | ⭐⭐⭐ | 可用，但结构可能不清晰 |
| PPT/PPTX | ⭐⭐ | 不推荐，切片质量难以保证 |
| 图片扫描件 | ⭐ | 不推荐，需要 OCR |

#### 4.2.2 增强文档元数据

**入库时自动提取**：

```python
{
    # 基础信息
    "doc_id": "case_001",
    "title": "XX村乡村旅游发展规划",
    "doc_type": "case",  # case/policy/guide/tech

    # 地理信息
    "province": "广东省",
    "city": "惠州市",
    "county": "博罗县",
    "town": "长宁镇",

    # 主题标签
    "themes": ["乡村旅游", "产业发展", "乡村振兴"],
    "industry_type": ["旅游业", "康养产业"],

    # 资源特征
    "resource_type": ["山区", "温泉", "古村落", "宗教文化"],
    "development_stage": "规划阶段",  # 规划/建设/运营

    # 内容摘要
    "summary": "...",
    "key_points": [...],
    "success_factors": [...],

    # 适用范围
    "applicable_regions": ["华南地区", "山区", "旅游型乡村"],
    "reference_value": "high"  # high/medium/low
}
```

### 4.3 长期方案（差异化优势）

#### 4.3.1 交互式规划

**用户输入村庄基本信息** → **系统自动匹配相似案例** → **生成定制化发展建议**

```
用户输入：
- 省份：湖南省
- 地形：山区
- 人口：2000人
- 主要资源：竹林、溪流
- 发展意向：乡村旅游

系统处理：
1. 检索相似案例（山区+旅游+竹林）
2. 检索湖南省级政策支持
3. 聚合生成建议

输出：
- 定制化发展建议
- 相似案例参考
- 适用政策支持
- 实施要点提醒
```

**前端展示**：

**当知识库无法直接回答时**：


## 六、技术实现要点

### 6.1 检索增强

**当前检索工具**（`src/rag/core/tools.py`）：
- `document_list` - 列出文档
- `document_overview` - 文档概览
- `knowledge_search` - 全文检索
- `key_points_search` - 要点检索

**建议增强**：
1. 添加 `similar_case_search` - 相似案例检索（按资源类型、产业类型匹配）
2. 添加 `policy_search` - 政策检索（按地区、主题过滤）
3. 增强元数据过滤能力

### 6.2 回答模板

**当前输出格式**（`planning.yaml`）：
```yaml
output_format:
  - 核心建议（2-3条）
  - 政策依据
  - 参考案例
  - 实施要点
  - 资源链接
```

**建议修改为**：
```yaml
output_format:
  - 回答摘要（一句话概括）
  - 核心建议（带来源引用）
  - 📖 引用来源列表
  - 📌 相似案例参考（如有）
  - 💡 补充信息提示（如需用户提供更多信息）
```

### 6.3 前端展示

**当前状态**：
- 前端已支持知识库开关
- 回答以 Markdown 渲染

**建议增强**：
1. 来源引用可点击跳转
2. 案例卡片展示
3. 引导式问答界面

## 七、风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 知识库扩充不足 | 用户价值有限 | 优先补充高价值内容，设置合理预期 |
| 用户提问过于具体 | 无法直接回答 | 引导用户提供信息，提供相似案例 |
| 来源引用不准确 | 降低可信度 | 提高检索质量，支持用户反馈 |
| 回答与通用大模型差异不明显 | 用户流失 | 强化来源标注，提供可追溯性 |

---

## 八、总结

规划技能的核心问题在于**定位宏大但知识库空洞**。解决思路：

1. **短期**：调整定位，优化回答模板，诚实告知边界
2. **中期**：扩充知识库，增强元数据，提高检索质量
3. **长期**：交互式规划，来源可追溯，差异化体验

**最关键的是知识库内容建设**——没有足够的内容支撑，任何技术优化都是空中楼阁。
