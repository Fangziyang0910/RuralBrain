## 🖼️ 图像检测功能测试用例

### 用例1：病虫害检测

**测试问题**：
```
请帮我检测这张图片中的病虫害，并给出防治建议
```

**操作步骤**：上传病虫害图片，输入测试问题

**预期效果**：
- 工具调用：`pest_detection_tool` 卡片
- 检测结果：正确识别病虫害种类和数量
- AI输出：检测结果摘要 → 危害分析 → 综合防治方案 → 预防建议
- 输出质量：专业详细，包含具体措施（药剂配比、使用方法等）
- 可视化：返回标注后的检测结果图片

---

### 用例2：大米品种识别

**测试问题**：
```
请帮我识别这张图片中的大米品种
```

**操作步骤**：上传大米图片，输入测试问题

**预期效果**：
- 工具调用：`rice_detection_tool` 卡片
- 识别结果：正确识别大米品种和数量（支持5种品种）
- AI输出：检测结果 → 品种特点分析 → 混合烹饪建议 → 储存方法 → 品质观察
- 输出质量：详细参数（米水比例、烹饪时间等），使用emoji增强可读性
- 可视化：返回标注后的识别结果图片

---

### 用例3：奶牛检测

**测试问题**：
```
请帮我数一下这张图片中有多少头牛
```

**操作步骤**：上传包含奶牛的图片，输入测试问题

**预期效果**：
- 工具调用：`cow_detection_tool` 卡片
- 数量统计：正确统计奶牛数量（允许±1误差）
- AI输出：检测结果摘要 → 分布分析 → 饲养管理建议 → 疫病防控 → 繁殖管理 → 环境控制 → 温馨提示
- 输出质量：详细参数（饲料比例、体温范围等），分类清晰
- 可视化：返回标注后的检测框图片
