# 新疆伊吾县：因地制宜 分类施策 着力打造边疆民族地区乡村振兴示范村

> **来源**：农业农村部发展规划司
> **日期**：2026-03-25
> **原文链接**：https://jhs.moa.gov.cn/xczx/202603/t20260325_6482603.htm

---

## 概述

伊吾县按照自治区党委、政府关于开展乡村振兴示范村建设的部署安排，立足边境少数民族地区实际，选取基础条件好、发展优势明显的**克尔赛、幻彩园、新丝路3个村**作为试点，率先开展乡村振兴示范村建设，因地制宜、分类施策，推动特色主导产业不断壮大，乡村面貌发生可喜变化，农民生活水平明显提高，向上向善蔚然成风。

---

## 一、科学规划、合理布局，明晰思路绘蓝图

### 1. 突出规划引领

根据《伊吾县国土空间总体规划》，立足地处蒙新高原、地势南高北低、"三山连三谷"地形地貌特点，结合县域"两横一纵"交通分布，制定乡村振兴示范村建设规划。

**三个片区划分**：
| 片区 | 村数 | 发展方向 |
|------|------|----------|
| 东部特色林果区 | 3个村（含新丝路） | 特色林果 |
| 西部特色养殖区 | 10个村（含幻彩园） | 特色养殖 |
| 北部特色种植区 | 7个村（含克尔赛） | 特色种植 |

### 2. 突出功能引领

**四类村庄分类**：
| 类型 | 村庄 | 重点任务 |
|------|------|----------|
| **产业带动类**（5个） | 幻彩园、杏花苑等 | 做"土特产"文章，促进产业兴旺 |
| **集聚提升类**（8个） | 克尔赛、甘沟等 | 完善基础设施、提升公共服务 |
| **城郊融合类**（5个） | 新丝路、和顺园等 | 完善治理体系、服务城镇发展 |
| **撤并整合类**（2个） | 沙梁子、夏尔吾依来 | 解决民生保障、有序推进撤并 |

### 3. 突出标准引领

围绕"**四个好**"目标，确定15项评价指标：

| 目标 | 具体标准 |
|------|----------|
| **规划好** | 每个示范村编制多规合一的村庄规划 |
| **产业好** | 主导产业产值占比≥70%，人均可支配收入增速高于全区平均 |
| **环境好** | 卫生厕所、垃圾处理、污水治理率均≥90%，安全饮水≥98%，安全住房100% |
| **治理好** | "五个好"党支部，积分制/清单制全面运用，文明家庭/星级文明户≥80%，满意度≥98% |

## 二、因地制宜、挖掘潜力，多措并举抓示范

对标"四个好"要求，3个示范村率先编制完成"多规合一"村庄规划，每个村：

**资金保障**：
- 自治区财政支持：**1000万元**
- 县财政配套：**1000万元**
- 撬动社会投资：约**900万元**

### 1. 坚持因村施策，培育壮大特色优势产业

立足资源禀赋，通过"**保底收益+二次分红**"、"**租金+薪金+股金**"等方式，让农民分享产业增值收益。

#### 幻彩园村：骆驼+沙棘双产业

| 指标 | 数值 |
|------|------|
| 养殖骆驼 | **6300峰** |
| 种植沙棘 | **2.4万亩** |
| 年产驼奶 | **1500吨** |
| 年产沙棘 | **800余吨** |
| 入驻企业 | **8家**（中驼等） |
| 深加工产品 | **20余种** |
| 年销售额 | **2.5亿元** |

#### 克尔赛村：乡村旅游+民俗风情

依托毗邻国家4A级胡杨林景区：
- 改造**26座**闲置农房（老茶馆、小酒馆、咖啡屋、农家乐）
- 建成"一户一景"民俗风情街
- 年接待游客**2万人次**
- 带动**600余人**从事旅游服务
- 年人均收入**4.2万元**

#### 新丝路村：戍边文化+边境旅游

- 探索"戍边文化+旅游"发展模式
- 发掘"古兵城"旅游资源
- 鼓励创作"农民画"
- "梵高"奶奶的"石头画"馆成为旅游打卡地
- 建立社会化服务组织**3个**
- 流转集体土地**1900余亩**
- 托管牲畜**1000余头（只）**
- 村集体经济收入**130万元**
- 向**230户**村民分红**50余万元**

### 2. 坚持内外兼修，着力提升乡村美丽颜值

实施人居环境整治提升工程，开展"**三清三改两提升**"行动，推进"**四化**"同治。

**克尔赛村基础设施成效**：
| 指标 | 数值 |
|------|------|
| 新铺设柏油路 | **3.9公里** |
| 供暖线 | **2.6公里** |
| 供排水管线 | **4.8公里** |
| 卫生厕所普及率 | **95%** |
| 生活污水治理率 | **100%** |
| 生活垃圾处理率 | **100%** |
| 村庄绿化覆盖率 | **30%以上** |
| 美丽庭院建设率 | **90%以上** |

实现水、电、路、气、通信"**五联五通**"，做到：
- 排污供水"一张网"
- 环卫保洁"一支队"
- 垃圾清运"一趟车"

### 3. 坚持多方联动，不断提高乡村善治水平

**创新"党建+"模式**：
- 常态化落实"**三清三掌握**"机制
  - 清楚村情、社情、民情
  - 掌握流动人口、困难群体、热点问题
- 开展天山脚下"一家亲"上门服务

**积分制、清单制全覆盖**：
- 村委会设立积分超市，每季度兑换一次
- 制定村民自治事项、村级小微权力和公共服务事项"**三个清单**"

**边境治理机制**：
- "村党支部+边境派出所"管理机制
- "网格长+微网格长+网格员"网格化管理体系
- "人在网格行、事在网上办、一网全覆盖"基层社会微治理格局

**新丝路村治理成效**：
| 指标 | 数值 |
|------|------|
| 连续无刑事案件 | **45年** |
| 矛盾纠纷调处化解率 | **97%以上** |
| 群众满意度 | **98%以上** |

## 三、汇集要素、凝聚合力，协同联动强保障

### 1. 强化组织领导

**工作责任制**：
- 县委书记、县长任"**双组长**"
- 设立**7个专项小组**：
  - 村庄规划
  - 产业发展
  - 环境整治
  - 乡村建设
  - 乡村治理
  - 人才保障
  - 资金保障

落实四项重点任务，县委书记定期调度项目进展。

### 2. 强化包联助力

- 对接自治区部门单位包联助力示范村建设
- 深入开展"**万企兴万村**"行动
- 自治区定点帮扶单位、驻伊企业等包联助力3个示范村

### 3. 强化示范带动

- 组织3个示范村与周边村建立结对帮扶关系
- 召开示范建设现场观摩会
- 引导各村照着学、跟着干，梯次推进示范村建设

## 经验总结

### 可复制要素

1. **四类村庄分类**：产业带动类、集聚提升类、城郊融合类、撤并整合类
2. **"四个好"标准**：规划好、产业好、环境好、治理好
3. **"三清三掌握"机制**：清楚村情社情民情，掌握流动人口困难群体热点问题
4. **"三金"收益模式**：租金+薪金+股金
5. **边境治理机制**：村党支部+边境派出所

### 核心创新点

| 创新点 | 说明 |
|------|------|
| 双组长责任制 | 县委书记+县长双组长 |
| 网格化治理 | 网格长+微网格长+网格员三级体系 |
| 戍边文化+旅游 | 古兵城、农民画、石头画馆 |
| 积分制全覆盖 | 积分超市、每季度兑换 |

- 边疆民族地区乡村振兴参考

- 基层社会治理模式推广
