# 江苏南京溧水区：以三"多"合一改革为途径 探索新时代"千万工程"溧水实践

> **来源**：农业农村部发展规划司
> **日期**：2025-12-04
> **原文链接**：https://jhs.moa.gov.cn/lsfz/202512/t20251204_6479459.htm

---

## 概述

江苏省南京市溧水区深入学习运用"千万工程"经验，充分发挥国家城乡融合发展试验区、南京国家农业高新技术产业示范区叠加优势，探索：

- 乡村规划布局"**多图合一**"
- 资源整合"**多头合一**"
- 管理队伍"**多员合一**"

以系统思维提高乡村资源配置效率，充分激发人、地、钱等要素活力。

**核心成效**（2024年）：
| 指标 | 数值 |
|------|------|
| 地区生产总值 | **1110.60亿元**（+5.7%） |
| 农村居民人均可支配收入 | **38110元**（+5.3%） |

---

## 一、以"高位推动"抓牢"先"机

### 1. 高位统筹强引领

- 把学习运用"千万工程"经验作为推进乡村全面振兴的重要抓手
- 实施"**一把手工程**"
- 构建以区委、区政府主要负责同志为"领头雁"、分管负责同志具体推进的组织领导体系
- 区委主要负责同志亲自领办，新年首会以"千万工程"为主题

### 2. 精准施策出方案

制定《新时代"千万工程"溧水新实践十项行动》年度工作方案，以三"多"合一改革为切入口，分年度将"五大振兴"要求融入溧水新实践十项行动。

### 3. 细化任务抓落实

- 聚焦规划引领塑形、和美乡村建设等十项行动
- 明确牵头单位、工作目标、重点任务和责任分工
- 健全"**区委月研究、政府半月调度、分管领导周例会**"常态化调度机制

---

## 二、以"多图合一"深挖"地"的潜力

坚持规划先行，打破部门壁垒，整合各类空间数据资源，变"多张图"为"一张图"，开发涵盖**9大类服务**的"多图合一"系统。

### 1. 盘活土地"存量"

系统设置**10个应用模型**：
- 耕地后备资源
- 管理林地认定
- 管理现状地类
- ...

**创新举措**：
- 点状供地
- 宅基地集中整治入市
- "**无想院子**"**10种**农村闲置资源盘活模式
- 颁发闲置农房使用权流转鉴证书

**成效**：累计盘活农村集体闲置资源资产项目**130余个**。

### 2. 扩大美丽"增量"

**规划成效**：
- 东屏街道长乐、丽山、白鹿**3个**村庄规划入选首批国土空间规划优秀案例

**村庄分类**：
| 类型 | 内容 |
|------|------|
| 清洁类 | 基础整治 |
| 整治提升类 | 重点提升 |
| 美丽宜居类 | 示范引领 |

**"三口三化"行动**：
- 村口、塘口、门口
- 洁化、绿化、美化

**基础设施成效**：
| 指标 | 数值 |
|------|------|
| 改造农村电网低压线路 | **530公里** |
| 新改建村组连接道路 | **41公里** |
| 农村生活垃圾集中收运处理 | **全覆盖** |
| 垃圾分类 | **全覆盖** |
| 污水处理 | **全覆盖** |

### 3. 提升融合"质量"

**物流网络**：
| 指标 | 数值 |
|------|------|
| 改造提升镇街级"交邮快供+"服务站 | **8个** |
| 村级服务点 | **91个** |
| 融合公交线路 | **22条** |
| 日均下行进村快件 | **1.5万件** |
| 年均带动农产品销售 | **超1000万元** |

特色农产品销售实现"市内T+0当日达""省内T+1次晨达"。

## 三、以"多头合一"用足"财"的效力

出台《关于进一步加强涉农资金资源要素统筹整合 加快农业农村现代化的意见》，对目标一致、性质相同、用途相近的各级涉农资金项目进行归并整合。

**资金整合成效**：
- 2022年以来累计整合超**30亿元**涉农资金
- 重点支持稳产保供、现代农业、绿色发展、农村公共服务和富民强村建设

### 1. 筑牢"保供"根基

| 指标 | 数值 |
|------|------|
| 统筹涉农资金 | **2.5亿元** |
| 年均水利工程建设投资 | **超3亿元** |
| 建成高标准农田 | **22.62万亩** |
| 绿色优质农产品占比 | **91.36%** |

### 2. 推进"一区多园"建设

| 指标 | 数值 |
|------|------|
| 统筹资金 | **9000多万元** |
| 高校院所 | **7家** |
| 国家及省市科研平台 | **102个** |
| 七大农业特色产业综合产值 | **超10亿元** |

**七大特色产业**：
- 优质粮油
- 特色林果
- 设施蔬菜
- 有机农业
- 特种水产
- 优质畜禽
- 休闲农业

### 3. 提升"均等服务"品质

每年统筹**6200万元**资金，聚焦"一老一小"等领域：

|------|------|

## 四、以"多员合一"激发"人"的活力

通过"多员合一"改革，实现职责不减、人员精简、管理顺畅、效率提高。

**改革成效**：
| 指标 | 数值 |
|------|------|
| 全区村社数量 | **84个** |
| 精简人员 | **631人** |
| 降低人员成本 | **约553.34万元/年** |
| 整合后人均年薪酬提高 | **0.9万元** |

### 1. 优化治理队伍

- 通过网格优化、职能整合、片区包干、村民共治
- 从外出务工返乡人员、返乡创业大学生、退役军人等群体中选拔管护员
- 累计储备村社干部后备人才**392人**
- 择优选派**113名**"90后"干部担任驻村第一书记

### 2. 提升治理能力

**村干部保障体系**：
- 区财政每年统筹**8200多万元**
- "岗级薪酬+普惠年金+定额补助"

实施村社书记头雁集群"丰羽强翅"工程，落实优秀村社书记纳入事业编制人员管理政策。

### 3. 提高治理效率

- 创新推进"精网微格"和"警网高效融合"
- 规范警务室、"蒲公英"融合法庭等一体建设运行
- 打造"智慧社区综合信息平台"
- 将乡村治理中各项事务转化为量化积分

## 经验总结

### 可复制要素

1. **三"多"合一改革**：多图合一、多头合一、多员合一
2. **"无想院子"10种盘活模式**：农村闲置资源盘活
3. **"三口三化"行动**：村口塘口门口、洁化绿化美化
4. **村干部"岗级薪酬+普惠年金+定额补助"保障体系**
5. **"精网微格"和"警网高效融合"**：治理创新

### 适用范围

- 城乡融合发展试验区建设参考
- 涉农资金整合机制借鉴
- 乡村治理人才队伍建设参考
- 农村闲置资源盘活模式推广
