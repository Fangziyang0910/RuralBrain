# 湖南祁阳市：园区牵引 联动发展 积极探索片区化推进乡村振兴路径

> **来源**：农业农村部发展规划司
> **日期**：2026-01-27
> **原文链接**：https://jhs.moa.gov.cn/lsfz/202601/t20260127_6481054.htm

---

## 概述

湖南省祁阳市坚持以学习运用"千万工程"经验为引领，把发展壮大主导产业作为推进乡村全面振兴先手棋，以园区为牵引，联动园区附近**20个行政村**共同发展，一体推进农村人居环境整治和基础设施建设，探索"**1+20**"的中部丘陵地区片区化推进乡村全面振兴路径，有力促进了产业融合发展、村容村貌干净整洁、基础设施改善提升。

---

## 一、坚持园区带动，明确片区化推进路径

### 1. 强化理念引领

深入学习运用"千万工程"经验蕴含的理念机制方法：

- 坚持典型带动和面上推广相结合
- 围绕国家农业现代化示范区等建设
- 确立"**园区引领、片区发展、梯次推进**"思路

制定"1+20"乡村振兴片区建设实施方案，立足本地特色产业：
- 优质稻
- 油菜
- 果蔬
- 油茶

逐步形成园区牵引、产村融合的乡村振兴格局。

### 2. 强化规划引领

围绕打造"三区"目标：
- 全省人居环境样板区
- 乡村振兴先行区
- 基层治理创新区

绘制农业农村现代化总体建设规划图，编制祁阳"1+20"乡村振兴重点片区村庄规划，统筹衔接：
- 省级现代农业产业园
- 贵澳油茶产业园
- 广垦油茶产业园

明确路线图、时间表、任务书，倒排工期，挂图作战。

### 3. 强化标准引领

出台文件：
- 《祁阳市乡村振兴建设与评价指南》
- 《祁阳市乡村振兴"1+20"示范区建设绩效评估办法》

明确片区产业发展、基础设施建设等目标任务和创建评价认定指标，形成"**建有规范、补有标准、管有办法、质有保障**"的工作体系。

## 二、统筹"三区"建设，一体推进农业农村现代化

### 1. 聚焦兴产业，着力建设"大产区"

完善全产业链，培育壮大新兴农业经营主体，打造现代粮油产业集群。

**科技支撑**：
- 柏连阳院士创新团队工作室
- 中国农科院官山坪红壤实验站

**产业成效**：
| 指标 | 数值 |
|------|------|
| 片区粮油产业产值 | **21亿元** |
| 占优势主导产业总产值 | **63%** |
| 油料作物种植面积 | **18万亩** |
| 粤港澳大湾区"菜篮子"认证基地 | **25个** |
| 国家级、省级农业产业化龙头企业 | **11家** |
| 农产品加工产值 | **200亿元** |

### 2. 聚焦强设施，着力建设"大园区"

积极推进片区内基础设施建设。

**农业生产设施**：
| 指标 | 数值 |
|------|------|
| 高标准农田 | **9.32万亩**（占耕地81%） |
| 智能集中育秧中心 | **8处**（11万平方米） |
| 水肥一体化设施农业 | **3.25万亩** |
| 粮油烘干中心 | **5个** |
| 油茶果初加工和仓储物流中心 | **6个** |

**农村基础设施**："**七张网**"建设
- 水、电、路、气、讯、广电、物流

| 指标 | 数值 |
|------|------|
| 建设路网 | **96公里** |
| 5G基站 | **6个** |
| 生态停车场 | **4个** |
| 天然气管网 | **23.5公里** |

### 3. 聚焦优生态，着力建设"大景区"

坚持生态优先、绿色发展，践行绿水青山就是金山银山理念。

**生态成效**：
| 指标 | 数值 |
|------|------|
| 水质优良率 | **100%** |
| 绿色标准化基地 | **22个** |
| 绿色、有机、地理标志农产品认证 | **26个** |
| "中国驰名商标" | **2个** |
| 中国好粮油品牌 | **8个** |

**旅游发展**：
- 所有行政村全部获评地市级以上"和美湘村"重点村
- 建成油茶博览馆
- 唐家山景区创建为国家**4A级旅游景区**
- 年接待游客**20多万人次**

## 三、强化机制创新，提升要素保障水平

### 1. 坚持高位推动

扛稳五级书记抓乡村振兴政治责任：

- 成立"1+20"片区化推进乡村振兴领导小组
- 市委书记任组长
- 建立联席会议制度
- 建立工作月例会制度

### 2. 健全工作体系

构建市级统筹、镇村主责、村民主体、上下联动的工作机制。

**"四个一"责任体系**：
- 1名联村市级领导
- 1个市直联村牵头单位
- 1名驻村镇班子成员
- 1支驻村帮扶工作队

**村"两委"带头人选拔**：
从致富能手、外出务工经商返乡人员、退伍军人、返乡大学生等优秀人才中产生。

### 3. 强化要素保障

创新"**五元投入**"机制：
1. 财政引导奖补
2. 项目整合倾斜
3. 引入社会资本
4. 鼓励群众自筹
5. 动员能人资助

**资金成效**：
| 指标 | 数值 |
|------|------|
| 筹集资金 | **3.2亿元** |
| 撬动社会资本 | **12亿元** |

**人才支持**：
- 组建**3支**人才小分队
- 选派**15名**科技人才下沉片区
- 派驻科技特派员开展科技服务和创业带动全覆盖

## 经验总结

### 可复制要素

1. **"1+20"片区化推进模式**：园区牵引、联动发展
2. **"三区"建设目标**：大产区、大园区、大景区
3. **"七张网"基础设施**：水电路气讯广电物流
4. **"四个一"责任体系**：1领导+1单位+1成员+1工作队
5. **"五元投入"机制**：财政+项目+社会资本+群众+能人

### 核心创新点

| 创新点 | 说明 |
|------|------|
| 片区化推进 | 1个园区带动20个行政村 |
| 产村融合 | 产业园区与村庄一体规划 |
| 科技支撑 | 院士工作室+农科院实验站 |

### 适用范围

- 中部丘陵地区乡村振兴参考
- 片区化推进模式借鉴
- 产业园区带动型发展参考
- 多元投入机制参考
