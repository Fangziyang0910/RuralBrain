# 福建省：统筹山海、城乡、工农关系 探索区域协调发展和城乡融合发展新路

> **来源**：农业农村部发展规划司
> **日期**：2025-11-14
> **原文链接**：https://jhs.moa.gov.cn/lsfz/202511/t20251114_6478925.htm

---

## 概述

福建认真贯彻落实习近平总书记在福建考察时关于"在推动区域协调发展和城乡融合发展上作示范"的重要讲话精神，立足"山"与"海"双重资源，以缩小地区差距、城乡差距、收入差距为主攻方向，统筹实施区域协调发展战略、新型城镇化战略、乡村振兴战略。

**核心成效**（2024年）：
| 指标 | 数值 |
|------|------|
| 居民人均可支配收入最高与最低设区市比值 | **2.05**（均衡性全国经济大省第3位） |
| 城乡居民人均可支配收入比 | **2.06**（优于全国平均） |
| 城乡居民人均生活消费支出比 | **1.72**（优于全国平均） |

## 一、以新时代山海协作为抓手推动区域协调发展

### 1. 强化两大都市圈牵引作用

福州都市圈、厦漳泉都市圈涵盖沿海所有城镇，经济总量分别约占全省的**1/3**和**1/2**。

**完善一体化发展机制**：
- 2021年和2024年相继出台福州都市圈、厦漳泉都市圈发展规划
- 建立健全都市圈协商合作、规划协调、政策协同、社会参与等协调发展机制

**提升同城化发展水平**：
- 实施福州滨海快线、厦漳泉城际铁路等标志性项目
- 建设中国东南（福建）科学城、厦门科学城、泉州时空科创基地等国家级创新平台

### 2. 强化老区苏区振兴发展

**省领导挂钩帮扶机制**：
| 指标 | 数值 |
|------|------|
| 省领导挂钩 | **38位**省领导挂钩**38个**县 |
| 省直单位挂钩 | **192个** |
| 累计支持项目 | **4000多个** |
| 落实帮扶资金 | **150多亿元** |

**增强内生发展动力**：
- 推进闽西革命老区高质量发展示范区建设
- 深化沪明（上海—三明）、广龙（广州—龙岩）对口合作
- 2024年龙岩、三明人均GDP在全国20个革命老区重点城市中分别位列**第一、第二**

**"万企兴万村"行动**：
| 指标 | 数值 |
|------|------|
| 参与民营企业/商会 | **3788家** |
| "兴村"数量 | **3288个** |
| 产业帮扶资金 | **166.1亿元** |
| 公益捐赠资金 | **64.8亿元** |

### 3. 强化山区沿海对口协作

**拓展产业合作载体**：
- 建设厦龙合作区、泉三高端装备产业园、南平（福州）产业创新孵化中心等**6个**重点"产业飞地"和"科创飞地"

**畅通交通互联**：
- 建成"两纵三横"综合交通运输大通道
- 实现全省铁路环形闭合

## 二、以县域为切入点推动城乡融合发展

### 1. 推进城乡一体布局

构建"设区市中心城区—县城—乡镇"城乡空间体系。

**村庄分类**（全省**14424个**村）：
| 类型 | 说明 |
|------|------|
| 城郊融合类 | 融入城市 |
| 集聚提升类 | 重点发展 |
| 稳定改善类 | 巩固提升 |
| 文化传承类 | 保护传承 |
| 民族团结类 | 民族特色 |
| 海岛发展类 | 海岛开发 |
| 侨台赓续类 | 侨台特色 |
| 收缩待定类 | 待定发展 |
| 搬迁撤并类 | 逐步撤并 |

### 2. 推进城乡一体发展

**县域重点产业链**：
- 出台《关于推进县域重点产业链高质量发展的意见》
- 全省建设县域重点产业链**164条**
- 2024年**11个**县域入选全国县域经济百强（全国第7位）

**"土特产"文章**：

| 农业产业强镇 | **108个** |
| "一村一品"专业村 | **2532个** |
| 农村居民人均可支配收入 | **28525元**（+6.7%） |

## 经验总结

### 可复制要素

1. **"山海协作"机制**：两大都市圈牵引+山区沿海对口协作
2. **省领导挂钩帮扶**：38位省领导挂钩38个县
3. **"一书记三大员"**：第一书记+科技特派员+金融助理+乡村振兴指导员
4. **九类村庄分类**：差异化发展路径
5. **闽台乡建乡创**：台湾团队驻村服务
