# 浙江绍兴市：坚持规划建设运营一体化 全域打造"和美越乡"共富片区

> **来源**：农业农村部发展规划司
> **日期**：2025-12-04
> **原文链接**：https://jhs.moa.gov.cn/lsfz/202512/t20251204_6479455.htm

---

## 概述

浙江省绍兴市坚持规划建设运营一体化理念，深入推进"**产村人文**"融合发展，全域打造"和美越乡"共富片区，促进乡村从"单打独斗"向"抱团共富"转变，不断增强乡村发展内生动力，有力推动美丽乡村、美丽经济、美好生活相互转化。

**核心成效**（2025年上半年）：
- 先行建设的**18个**共富片区
- 村均集体经济收入**165.8万元**
- 比全市平均高出**23.5万元**

---

## 一、统筹"三个步骤"，构建片区规划市域格局

### 1. 谋定总体布局

制定《全市域建设"和美越乡"共富片区实施方案》和片区建设导则，明确片区建设的总体目标、原则与框架。

**布局规模**：
| 指标 | 数值 |
|------|------|
| 共富片区总数 | **60个** |
| 跨乡镇片区 | 7个 |
| 跨县域片区 | 1个 |
| 辐射乡镇（街道） | **69个** |
| 辐射行政村（社） | **426个** |

在全市"**一心三带十轴**"整体架构下，实现对乡村的有效辐射带动。

### 2. 明确发展定位

根据各片区资源禀赋、产业基础、文化资源等，按**6个类型**因地制宜形成发展方案：

| 类型 | 特点 |
|------|------|
| 特色产业带动型 | 依托特色农业产业 |
| 在地文化激活型 | 挖掘本地文化资源 |
| 研学项目催生型 | 发展研学旅游 |
| 生态产品开发型 | 开发生态资源 |
| 人文旅居发展型 | 文化+旅居结合 |
| 等级景区创建型 | 打造旅游景区 |

2025年重点打造的**12个**共富片区均已完成方案制订，梳理形成重点工作清单和重点项目清单。

### 3. 形成空间导图

推动共富片区专项规划与国土空间规划衔接，按照共建共享、集约集成原则统筹布局：

**交通设施**：步行圈、骑行圈、车行圈、公共停车场

**业态场景**：打卡点、消费点、休闲点、乡村文化馆

**生活配套**：托育站、颐养站、医疗站、农民居住区

2025年启动建设的**20个**共富片区已全部完成专项规划修编。

## 二、创新"四联四共"，形成片区建设有效路径

### 1. 组织联建、项目共谋

建立由片区内村集体、经营主体、运营团队等组成的**片区联合党组织**，汇聚政府、金融、企业等各界力量。

**成效数据**：
| 指标 | 数值 |
|------|------|
| 片区联合党委（党组织） | **31个** |
| 2025年重点谋划项目 | **73个** |
| 总投资 | **14亿元** |

### 2. 产业联育、资源共推

打造片区产业集群，建设共富场景：
- 共富基地
- 共富工坊
- 共富市集
- 共富驿站

推动"山水林田湖地房"等资产资源整体激活，实现多村联合、片区联动、集群联营。

**成效数据**：
| 指标 | 数值 |
|------|------|
| 2024年建成共富片区 | 6个 |
| 共富场景 | **62个** |
| 带动农民就业 | **1547人** |
| 2025年利用闲置农房招引项目 | **105个** |
| 吸引社会资金 | **1.48亿元** |

**典型案例**：新昌县下岩贝·金山上共富片区多村联动，一月一主题，先后开展音乐节、山地越野赛等活动，成为网红打卡地。

### 3. 服务联享、爆款共创

片区化推动基础设施提标，协同优化公共服务，让村民和游客共享优质资源。

打造"三爆"产品：
- "用了还想用"的产品爆款
- "试了还想试"的文化爆款
- "来了还想来"的活动爆款

### 4. 环境联营、村民共情

统筹实施美丽田园、美丽村庄、美丽河湖等建设，一体化推动农村人居环境长效治理。

**典型案例**：柯桥区花香漓渚共富片区组建红色娘子军、"和"老师调解团等组织，积极参与片区建设，形成"兰乡有礼"乡风文明特色品牌。

## 三、聚焦四个维度，提升片区运营综合效益

### 1. 强村公司更强

鼓励组建股份制强村公司，采取多村合作、镇村联营等形式，整合利用片区内资源、资产、资金。

**成效数据**：
- 全市共**231家**强村公司参与片区或乡村运营

**典型案例**：越城区酒香有戏共富片区
- 盘活闲置农房
- 撬动项目投资**1200万元**
- 招引**12个**焕新业态入驻
- 带动就业**120人**

### 2. 返乡青年更多

加强"**引育用留**"人才政策全链条保障：
- 举办"乡村人才振兴"全球创新创业大赛
- 实施"农创保"试点
- 在片区内打造标杆型青年下乡实践站点

**成效数据**：
| 指标 | 数值 |
|------|------|
| 签约专业运营团队的片区 | **22个** |
| 吸引青年 | **226人** |

### 3. 联农机制更优

聚焦助农增收主线，推动乡村"土特产"向"一片一产""一片多产"转变。

**联农带农机制**：
- "村民股份众筹"
- "社会资本+村集体+农户"
- "企业+合作社+农户"

**典型案例**：嵊州市小吃经共富片区
- 发展小吃特色产业链
- 建设小吃产业园
- 新增就业岗位**100多个**
- 带动周边农户**3000多人**
- 人均年增收近**2万元**

### 4. 品牌价值更大

个性化培育村庄IP，通过创意手段建设各美其美的乡村组团，形成片区品牌矩阵。

**典型案例**：嵊州市西白山共富片区
- 村庄品牌："星宿小昆""红色沃基""艺术水竹"
- 共富品牌："西白1097""小昆阿婆"
- 年游客量超**70万人次**

## 经验总结

### 可复制要素

1. **"一心三带十轴"整体架构**：市域统筹布局
2. **"四联四共"机制**：组织联建、产业联育、服务联享、环境联营
3. **"三爆"产品策略**：产品爆款、文化爆款、活动爆款
4. **"引育用留"人才政策**：全链条保障
5. **多种联农带农机制**：股份众筹、社会资本+村集体+农户等

### 核心创新点

| 创新点 | 说明 |
|------|------|
| 规划建设运营一体化 | 全链条统筹推进 |
| 片区联合党组织 | 多村联合治理 |
| 共富场景建设 | 基地、工坊、市集、驿站 |
| 村庄IP培育 | 个性化品牌矩阵 |

### 适用范围

- 东部发达地区乡村振兴参考
- 片区化共富模式借鉴
- 乡村运营团队建设参考
- 联农带农机制推广
