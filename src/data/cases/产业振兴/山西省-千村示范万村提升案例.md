# 山西省：创新体制机制 因地制宜施策 努力绘就乡村全面振兴山西画卷

> **来源**：农业农村部发展规划司
> **日期**：2026-01-27
> **原文链接**：https://jhs.moa.gov.cn/lsfz/202601/t20260127_6481041.htm

---

## 概述

山西省深入学习运用"千万工程"经验，结合地域资源禀赋、文化脉络和产业基础，突出"晋风晋韵"特色，以"**千村示范、万村提升、全面整治**"工程为抓手，构建起"政策精准配套、资源高效整合、发展有序分类"的全域乡村振兴推进机制，走出了一条以体制机制创新、系统赋能乡村振兴的实践路径。

---

## 一、做法成效

### 1. 统分结合，建立高效协同领导机制

**加强组织领导**：
- 山西省委省政府把学习运用"千万工程"经验作为"**一把手**"工程
- 主要负责同志牵头研究出台《学习践行"千万工程"经验全面推进乡村振兴实施意见》
- 连续三年主持召开全省现场推进会

**强化协同贯通**：

省级层面构建工作格局：
- 省委农村工作领导小组牵头抓总
- 省领导分工负责
- 工作专班协同推进

**六个工作专班**：
| 牵头单位 | 专班职责 |
|----------|----------|
| 自然资源厅 | 村庄规划 |
| 发展改革委 | 城乡融合发展 |
| 农业农村厅 | 农村人居环境整治 |
| 省委宣传部 | 乡村产业发展 |
| 省委宣传部 | 农村精神文明建设 |
| 省委组织部 | 党建引领乡村治理 |

做到"**一个专班、一套方案、一抓到底**"。

**健全推进机制**：
- "定期调度、精准督导、动态推进"工作机制
- 全链条资金整合监管机制
- 出台专项资金管理、激励考核、建设指引等配套文件

### 2. 统筹推进，提升乡村发展质量成色

**科学分类、梯次推进**：

对全省**1.8万个**行政村进行全面摸底，划分为三类：

| 类型 | 数量 | 占比 |
|------|------|------|
| 精品示范村 | **719个** | - |
| 提档升级村 | **5421个** | - |
| 环境整治村 | 其余 | - |
| 累计建设（示范+提档） | **6140个** | **32.5%** |

明确"示范一批、提升一批、整治一批"的梯次化建设路径。

**夯实基础、城乡一体**：

"十四五"以来成效：
| 指标 | 数值 |
|------|------|
| 新改建"四好农村路" | **19356公里** |
| 行政村通5G比例 | **93.8%** |
| 农村生活垃圾收运处置覆盖自然村 | **98%以上** |
| 新建城乡义务教育共同体 | **600个** |
| 新建农村区域养老服务中心 | **150个** |

**创新治理、繁荣文化**：
- 广泛运用积分制、清单制及数字化手段
- 深入整治高额彩礼、大操大办等陋习
- 大力传承三晋优秀传统文化
- 依托非遗展演、"村BA"、村跑等群众性文体活动

### 3. 多元保障，注入乡村全面振兴发展动能

**资金投入**（2024—2027年）：

省级财政计划筹集资金**100亿元**，差异化补助标准：

| 县类型 | 人均补助标准 |
|--------|-------------|
| 示范县 | 600元 |
| 推进县 | 800元 |
| 帮扶县 | 1000元 |

目前已落实**58.4亿元**。

**用地保障**：
- 为**36个脱贫县**每县安排**600亩**用地指标
- 新编县乡级国土空间规划安排不少于**10%**的建设用地指标保障乡村产业发展
- 对农村一二三产业融合发展重点项目建设用地做到应保尽保

**人才支撑**：
| 指标 | 数值 |
|------|------|
| 驻村工作队 | **7131支** |
| 驻村干部 | **2.2万名** |
| "乡村振兴万人计划"招聘大学生 | **2.1万名** |
| 实现"一村一名大学生" | **全覆盖** |

实施乡村人才振兴群雁行动，出台**13项**支持政策。

### 4. 凝聚共识，营造良好氛围

**深化学习交流**：
- 组织11个市委书记围绕学习运用"千万工程"经验开展电视专题访谈

**强化干部培训**：
- 连续两年举办山西省乡村振兴领导干部培训班
- 对精品示范村党组织书记进行全覆盖培训
- 引入**15家**规划团队授课

**加强示范引领**：
- 制作《乡村振兴 山西样板》等系列专题片
- 系统开展"'千万工程'看山西"全媒体宣传报道

## 二、经验启示

### 1. 坚持党的领导，发挥高位统筹与高效协同组织优势

落实五级书记抓乡村振兴责任，建立健全乡村振兴工作推进机制，有效避免"上热下冷"、"各自为战"。

### 2. 树立系统观念，推动城乡融合与乡村"五个振兴"有机统一

统筹新型城镇化与乡村全面振兴，坚持乡村产业、人才、文化、生态、组织"五个振兴"一体推进，形成城乡互促、协调发展的新格局。

### 3. 践行因地制宜，实现乡村发展与乡风民俗相得益彰

分类编制村庄规划，明确差异化发展方向，统筹考虑财力可承受、农民可接受、发展可持续。

### 4. 强化集成创新，促进要素供给与制度改革集成增效

坚持向改革要动力，有效破除体制机制障碍，推动"人、地、钱"等关键要素向乡村流动。

## 经验总结

### 可复制要素

1. **"千村示范、万村提升、全面整治"工程**：三级梯次推进
2. **"一个专班、一套方案、一抓到底"**：六个专班分工负责
3. **三类县差异化补助**：示范县600元、推进县800元、帮扶县1000元
4. **"一村一名大学生"全覆盖**：乡村人才振兴
5. **定期调度、精准督导、动态推进**：工作机制

### 适用范围

- 省级层面乡村振兴统筹推进参考
- 村庄分类建设标准借鉴
- 多元投入机制参考
- 人才振兴政策参考
