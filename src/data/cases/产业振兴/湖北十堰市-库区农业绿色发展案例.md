# 湖北十堰市：统筹高质量发展和高水平保护 扎实推进库区农业绿色发展

> **来源**：农业农村部发展规划司
> **日期**：2026-03-17
> **原文链接**：https://jhs.moa.gov.cn/lsfz/202603/t20260317_6482320.htm

---

## 概述

十堰市坚持把加快农业发展全面绿色转型作为落实长江大保护、推进乡村全面振兴的重要抓手，统筹推进高水平保护与高质量发展，因地制宜开发山水资源，全力打造绿色农产品输出地，加快探索一条具有山区特色的农业绿色发展之路。

---

## 一、以库区综合治理为载体，坚定不移保水护水

以生态约束倒逼产业升级，建立"**资源清单+负面清单**"管理制度，强化农业面源污染管控，规范规模化养殖污染处理，实现在保护中发展。

### 1. 强化保护守底线

积极推进退捕禁捕：

| 指标 | 数值 |
|------|------|
| 拆除库区网箱 | **18.2万只** |
| 拆除库汊围网 | **21.9万亩** |

建立农业野生植物和水产种质资源保护区：
- 野茶（骞林茶）、猕猴桃等农业野生植物原生境保护点
- 丹江鲌类国家级水产种质资源保护区
- 对农业野生植物和水产种质资源进行有效保护和可持续利用

### 2. 减量增效促转型

**化肥农药减量成效**：
| 指标 | 时间跨度 | 降幅 |
|------|----------|------|
| 化肥施用量 | 连续8年负增长 | 比2016年降低**38.9%** |
| 农药使用量 | 连续13年负增长 | 比2011年降低**54.0%** |

开展主要农作物重大病虫害绿色防控与统防统治：
- 以生物防治、物理防治代替农药防治
- 2025年主要农作物绿色防控覆盖率：**58.65%**
- 统防统治覆盖率：**48.76%**

**水质达标**：
- 27个省级及以上国控断面水质达标率：**100%**
- 优良率：**100%**

### 3. 资源利用提质效

**畜禽粪污处理**：
- 规模以上养殖场和养殖大户粪污环保处理设施实现全覆盖
- 2025年畜禽养殖粪污资源化利用率：**87%**

**农业废弃物综合利用**：
实现肥料化、饲料化、燃料化、原料化、基料化"五化"利用：

| 指标 | 2025年数值 | 对比全国 |
|------|------------|----------|
| 秸秆综合利用率 | **95.8%** | 高于全国水平 |
| 农膜回收率 | **85.8%** | 高于全国水平 |
| 农药包装废弃物回收率 | **77.7%** | 高于全国水平 |

---

## 二、以开发特色资源为重点，发展绿色低碳农业产业链

推进产业生态化和生态产业化，通过延长产业链、提升附加值，推动农产品加工转化，农文旅深度融合，促进生态效益与经济效益双赢。

### 1. 培育特色产业集群

全链条发展生态低碳产业：
- **食用菌**
- **中药材**
- **茶叶**

通过搭建供应链、重构产业链、提升价值链，为特色农产品赋予生态品牌价值。

**成效数据**：
| 指标 | 数值 |
|------|------|
| "三品一标"认证总数 | **480个以上** |
| 涉及农户 | **42万户** |
| 户均增收 | **7000元** |

### 2. 壮大区域公用品牌

建立从"**标牌到品牌、名牌、王牌**"的梯次培育机制：

- "武当山茶"品牌价值达**47.23亿元**

**展销活动**：
- 水源地绿色农产品博览会
- 大湾区绿色农产品贸易对接会
- 香港美食博览会十堰农产品展
- 日本、韩国十堰农产品专题推介

**销售成效**：
- 农产品市外销售率从2023年21.24%提升至**26.14%**

### 3. 开发农旅融合产业

**乡村精品民宿**：
- 武当山"师傅的山"
- 竹溪桃花岛

**乡村旅游景点**：
- 郧阳区香菇产业园
- 东方橄榄园
- 竹山五福龙井综合体

实现群众在家门口致富愿景。

**成效数据**（2025年）：
| 指标 | 数值 |
|------|------|
| 乡村旅游人次 | **7440万** |
| 乡村旅游收入 | **558亿元** |
| "中国美丽休闲乡村" | **7个** |
| 国家级森林康养建设试点 | **26个** |

## 三、以生态产品价值实现为目标，探索"两山"转化路径

以制度创新统筹保护与发展，创建第二轮国家生态产品价值实现机制试点地区和绿色金融改革创新试验区。

### 1. 健全生态产品经营开发机制

制定《十堰市生态产品总值核算规范（试行）》，率先在丹江口市、竹溪县成立"**两山**"转化运营平台：

**转化方式**：
- 颁发"生态资源受益权证"
- 颁发"两山"银行卡
- 推动碎片化生态资源的集中收储、规模流转和专业开发
- 畅通政府与市场、金融与产业、资源与资本对接渠道

**典型案例**：
| 地点 | 模式 | 成效 |
|------|------|------|
| 丹江口市习家店镇杏花村 | "两山"转化：群众得租金、分股金 | 户均增收**1.1万元** |
| 竹溪县 | 整合闲置茶园，引入社会资本开发大叶茶产品 | 茶园亩均增收**3000元** |

### 2. 完善绿色金融保障机制

加快绿色金融改革创新试验区建设：

**创新产品**：
- "**绿色发展贷**"
- "**碳林贷**"
- 水土保持生态产品规模化交易
- 可交易"**鄂林碳票**"
- "**林权贷**"融资用于投资智慧桔园、油橄榄等经济发展项目
- 取水权贷
- 排污权贷

**一揽子金融举措**：
- 直接融资+间接融资
- 把生态资源转化成绿色资本
- 破解"资源变现"困局

## 经验总结

### 可复制要素

1. **"资源清单+负面清单"管理制度**：生态约束倒逼产业升级
2. **绿色防控替代农药**：生物防治、物理防治替代化学防治
3. **"五化"综合利用**：肥料化、饲料化、燃料化、原料化、基料化
4. **"两山"转化运营平台**：生态资源受益权证、两山银行卡
5. **绿色金融创新**：碳林贷、鄂林碳票、林权贷等

### 核心创新点

| 创新点 | 说明 |
|------|------|
| 库区综合治理 | 退捕禁捕+网箱拆除+水质达标 |
| 减量增效 | 化肥8年负增长、农药13年负增长 |
| 产业生态化 | 食用菌、中药材、茶叶全链条发展 |
| 农旅融合 | 7440万人次、558亿元收入 |
| 生态产品价值实现 | 两山转化平台+绿色金融 |
