# 辽宁鞍山台安县：立足优势打造绿色低碳农业产业链 促进农业发展全面绿色转型

> **来源**：农业农村部发展规划司
> **日期**：2026-03-25
> **原文链接**：https://jhs.moa.gov.cn/lsfz/202603/t20260325_6482647.htm

---

## 概述

台安县牢固树立和践行绿水青山就是金山银山理念，立足资源禀赋，创新发展模式，统筹推进乡村生态保护修复和农村一二三产业融合发展，逐步形成**集聚化、链条化、绿色化协同推进**的农业发展全面绿色转型新格局。

---

## 一、立足资源优势，推动农业生产方式绿色转型

充分发挥农业大县资源禀赋，聚力种植业提质增效、养殖业生态扩容、加工业低碳集群，全面推动农业产业向集约化、绿色化转型。

### 1. 推进种植业绿色增量

推广绿色生产技术，激活土地资源潜能：

- 大力培育家庭农场、农民合作社等新型绿色经营主体
- 推动种植业规模集聚、设施升级与生态保护协同发展

**成效数据**：
| 指标 | 数值 |
|------|------|
| 家庭农场 | **421家** |
| 设施农业小区 | **81个** |
| 粮食年产量 | 稳定在**10亿斤以上** |
| 绿色蔬菜年产量 | 突破**62万吨** |

### 2. 加快养殖业绿色扩容

构建多元利益联结机制，推广种养结合、循环农业模式：

- 构建"**龙头企业+合作社+农户**"模式
- 推广种养结合、循环农业模式
- 强化粪污资源化利用
- 推动养殖小区标准化、清洁化建设

**成效数据**：
- 建成标准化养殖小区**700余个**
- 养殖户年均增收**2万元以上**

### 3. 促进加工业绿色发展

依托台安高新农业产业开发区，发展绿色农产品精深加工：

- 设立台安农业高质量发展产业引导基金
- 以绿色平台与政策赋能产业链低碳转型

**成效数据**（截至2025年底）：
| 指标 | 数值 |
|------|------|
| 规模以上农产品深加工企业 | **16家** |
| 国家农业产业化重点龙头企业 | **4家** |
| 农产品加工总产值 | **160亿元** |
| 占全县工业总产值比例 | **60%** |

逐步实现从农业大县向绿色农产品加工强县的跨越。

---

## 二、聚焦价值转化，推动农业产业链条化发展

坚持把农产品深加工产业作为台安的"金字招牌"和"支柱产业"，通过"引绿色项目、强低碳企业、聚生态链条"，持续激活县域经济绿色新动能。

### 1. 打造特色产业

紧紧围绕**白羽肉鸡**优势产业：

- 严格筛选引进符合环保标准、具备绿色生产能力的龙头企业
- 引导本土企业建立绿色养殖体系
- 推动白羽肉鸡纳入全国名特优新农产品资源普查名录

**品牌价值**："台安白羽肉鸡"品牌价值达**89亿元**

### 2. 补齐产业链条

聚焦白羽肉鸡食品深加工，推行"**零废弃**"生产模式：

- 将生产废料均转化为有机肥料或生物能源
- 构建"绿色生产—循环利用—低碳加工"全产业链闭环

**全链条环节**：
1. 种禽育繁
2. 规模养殖
3. 精深加工
4. 饲料生产
5. 副产物利用
6. 休闲农业

实现全链条绿色化改造。

### 3. 做强产业集群

将绿色发展理念延伸至生猪、肉牛、玉米、苹果等产业：

- 与快手公司合作搭建"**电商+产业**"推广平台
- 通过"可视化溯源"提升消费者信任度
- 推动全品类农产品深加工向"绿色化、多样化、智能化"迈进

---

## 三、服务生态振兴，推动农业生态保护修复

依托现有项目，系统推进种养资源集约利用、土壤沙化治理、产业体系绿色低碳转型，实现经济发展与生态环境保护同步提升。

### 1. 推动绿色种养循环

创新"**以地定养、以养促种**"模式：

- 实施畜禽粪污资源化利用项目
- 建成覆盖全县的粪污收储运网络
- 引入数字化技术实现全流程监管

**成效数据**（2025年）：
| 指标 | 数值 |
|------|------|
| 年处理畜禽粪便量 | 超**40万吨** |
| 畜禽粪污综合利用率 | **80.7%** |
| 化肥使用量下降 | **30%** |

### 2. 开展生态系统修复

实施退化林修复、森林抚育等工程：

- 完成多项绿化治理工程
- 完成**28个行政村**绿化改造
- 同步融合农业与生态
- 推广保护性耕作等措施
- 采用乔灌草结合方式种植耐旱树苗
- 提升植被成活率
- 鼓励种植抗旱果树与农作物

促进生态效益、经济效益双赢。

### 3. 发展绿色低碳产业

支持台安高新农业产业开发区构建绿色循环发展模式：

- 构建"**种养加一体、产供销联动**"绿色循环发展模式
- 积极探索光伏发电、生物质能等清洁能源技术的规模化应用
- 推动农业企业综合用能成本显著下降**20%**

助力农业发展全面绿色转型。

## 经验总结

### 可复制要素

1. **"以地定养、以养促种"模式**：种养循环，粪污资源化利用
2. **"零废弃"生产模式**：全产业链闭环，废料转化为肥料/能源
3. **多元利益联结机制**：龙头企业+合作社+农户
4. **数字化监管**：粪污收储运全流程数字化监控
5. **品牌价值打造**：白羽肉鸡品牌价值89亿元
6. **电商+产业平台**：可视化溯源提升消费者信任

### 核心创新点

| 创新点 | 说明 |
|------|------|
| 集聚化 | 种植业规模集聚、养殖小区标准化 |
| 集群化 | 加工业低碳集群，占工业总产值60% |
| 绿色化 | 粪污利用率80.7%，化肥减少30% |
| 链条化 | 从育繁到休闲农业全链条覆盖 |

### 适用范围

- 农业大县绿色转型参考
- 白羽肉鸡/生猪/肉牛等养殖业产业链借鉴
- 畜禽粪污资源化利用技术推广
- 农产品精深加工产业集群建设
