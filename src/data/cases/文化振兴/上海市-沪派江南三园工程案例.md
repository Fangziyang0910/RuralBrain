# 上海市：以"三园工程"建设为抓手 打造"沪派江南"宜居宜业和美乡村

> **来源**：农业农村部发展规划司
> **日期**：2025-09-17
> **原文链接**：https://jhs.moa.gov.cn/lsfz/202509/t20250917_6477405.htm

---

## 概述

上海市深入学习运用"千万工程"经验，以保护传承特色村落风貌为前提，以"**五划联动**"全周期规划管理为路径，全面推动：
- 绿色田园
- 美丽家园
- 幸福乐园

"三园工程"系统推进乡村产业发展、乡村建设、乡村治理，打造"沪派江南"和美乡村。

---

## 一、聚焦"五划联动"全周期管理

### 1. 开展整体谋划

制定实施乡村振兴战略实施意见，系统谋划"三园工程"作为本地版的"千万工程"，探索具有上海特色的超大城市乡村振兴道路。

### 2. 加强功能策划

**乡镇层面分类**：
| 类型 | 功能定位 |
|------|----------|
| 核心镇 | 强化综合服务、特色产业功能 |
| 中心镇 | 提升对周边区域带动能力 |
| 一般镇 | 满足周边城乡居民基本公共服务和就业需求 |

**村级层面分类引导**：
- 具有历史文化底蕴和风貌特色的村庄：重点保护
- 区位优势明显和产业资源丰富的村庄：保留发展
- 规模小、分布散的村庄：稳妥有序推进迁并

### 3. 编好空间规划

构建乡村详细规划数据库"**一张图**"，组织编制《上海市特色村落风貌保护传承专项规划》，构建沪派江南"**六域、八脉、十二意象**"的上海乡土乡村风貌空间结构。

### 4. 突出特色刻画

在全市**9个涉农区、108个乡镇**开展特色民居村落风貌保护调研普查：
- 形成"一村一报告"、"一区一册"调查成果
- 统筹划定**148个**乡村风貌单元
- 明确分层、分类、分区的规划策略和方案指引

### 5. 做好实施计划

制定系列方案：
- 上海市乡村振兴战略实施方案
- 推进农业高质量发展行动方案
- 上海市特色村落风貌保护传承行动方案

---

## 二、聚焦"三园工程"建设

### 1. 推进"绿色田园"建设

**发展绿色农业**：
- 打造**13个**绿色田园先行片区
- 2024年地产农产品绿色食品认证率达**32.6%**

**发展规模农业**：
- 引进知名龙头企业参与农业发展
- 推动建设现代化农业项目

**发展科技农业**：
| 指标 | 数值 |
|------|------|
| 建成粮食生产智慧农场 | **近7.36万亩** |
| 规划布局现代设施农业片区 | **12个** |
| 农业科技进步贡献率 | **80.6%** |

### 2. 推进"美丽家园"建设

**村庄示范建设**：
| 指标 | 数值 |
|------|------|
| "十四五"规划建设示范村 | **150个** |
| 已纳入创建计划 | **164个**（7个批次） |
| 累计入住新居农户 | **3.6万户**（2024年新增1.1万户） |

**农民相对集中居住路径**：
- 平移
- 上楼
- 货币有偿退出

### 3. 推进"幸福乐园"建设

**党建与治理深度融合**：
- 常态化开展"**四百**"大走访：走百家门、知百家情、解百家忧、暖百家心
- 深化"阳光村务工程"建设
- 全面推行村干部开放式办公
- 乡村治理"积分制"实践

**公共服务提升**：
| 指标 | 数值 |
|------|------|
| 城乡义务教育"五项标准"达标率 | **100%** |
| 行政村标准化村卫生室 | **全覆盖** |
| 累计建成农村养老示范睦邻点 | **3464个** |

## 三、聚焦健全完善推进机制

### 1. 健全工作机制

- 压实五级书记抓乡村振兴政治责任
- 制定《上海市乡村振兴责任制实施细则》
- 开发乡村振兴重点任务目标管理系统
- 实行"挂图作战"，清单化闭环化推进

### 2. 多元主体参与

**"三师联创"机制**：
- 规划师
- 建筑师
- 景观师

全程参与"沪派江南"营造工作，引进生态、文艺、体育等多领域专业人士助力。

### 3. 统筹要素投入

**资金保障**：
- 每个乡村振兴示范村市级奖补**2000万元**
- 用于发展乡村产业、改善乡村风貌、完善乡村基础设施、提升乡村治理能力

**用地保障**：
- 开展全域土地综合整治
- 支持现代设施农业、农民集中居住区等

### 4. 凝聚广泛共识

- 组织"乡村振兴示范村成果展示"
- 沪派江南行动"进行式"
- "乡土行纪"等活动

## 经验总结

### 可复制要素

1. **"五划联动"全周期管理**：谋划→策划→规划→刻画→计划
2. **"三园工程"**：绿色田园、美丽家园、幸福乐园
3. **"三师联创"机制**：规划师+建筑师+景观师
4. **"四百"大走访**：走百家门、知百家情、解百家忧、暖百家心
5. **"六域、八脉、十二意象"**：沪派江南风貌空间结构

### 适用范围

- 超大城市乡村振兴参考
- 特色村落风貌保护传承借鉴
- 全周期规划管理参考
- 多元主体参与机制推广
