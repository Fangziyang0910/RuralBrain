# 贵州遵义：统筹规划梯次推进 建设"四在农家·和美乡村"

> **来源**：农业农村部发展规划司
> **日期**：2026-02-28
> **原文链接**：https://jhs.moa.gov.cn/xczx/202602/t20260228_6481801.htm

---

## 概述

贵州省遵义市深入贯彻落实习近平总书记考察贵州时的重要讲话精神，学习运用"千万工程"经验，贯彻落实贵州省委、省政府关于"四在农家·和美乡村"建设的决策部署，立足实际统筹规划、梯次推进，围绕"富、学、乐、美"建设目标，积极引导群众共同决策、共同筹资、共建家园、共管共治、共享成果，不断提升乡村产业发展水平、乡村建设水平、乡村治理水平，奋力建设"望得见山、看得见水、记得住乡愁"的宜居宜业和美乡村。

---

## 一、围绕"三个结合"抓规划

把村庄规划作为乡村振兴先手棋，按照统筹兼顾、务实管用原则进行整体谋划，做到既管当下、又管长远。

### 1. 结合村情实际定目标

结合产业发展、乡村人才、人居环境、乡村治理、组织建设等实际情况，对全市有乡村振兴任务的**1728个行政村**进行综合研判，按"一类带动引领村、二类改进提升村、三类补短追赶村"进行分类建设：

- 每年根据工作进展和成效开展综合评估
- 力争用**4年时间**建成一类村**500个以上**
- 逐步消除三类村

### 2. 结合建设需求编规划

坚持需求导向，对集聚提升类、城郊融合类、特色保护类村庄进行分类指导：

- 推动有建设需求和发展需求的村庄抓紧编、提前编
- 目前全市**194个村**已完成"多规合一"实用性村庄规划编制

### 3. 结合群众意见建图则

按照务实管用原则，通过召开群众会广泛征集意见建议，因地制宜编制通俗易懂的**"一图一表一说明"**：

- 一张规划图
- 一张项目表
- 一张说明书

目前全市**1150个村**已编制"一图一表一说明"，实现一、二类村全覆盖。

## 二、围绕"四个明确"定标准

立足村庄规划实际，制定宜居宜业和美乡村建设实施细则，分类施策、循序渐进。

### 1. 明确建设内容

从"兴产业、育人才、强治理、树新风、优环境"等方面明确：

| 类型 | 内容数量 |
|------|----------|
| 基础内容 | 30项 |
| 提升内容 | 20项 |
| 底线任务 | 5项 |

县级每年初对照55项建设内容择优推荐一、二类村名单，针对性制定建设计划。

### 2. 明确资金保障

统筹各类资金向一类村倾斜：

- 乡村振兴衔接资金
- 东西部协作资金
- 改厕资金
- 生态环境、综合执法、文旅、民宗等部门资金

**2025年资金投入**：
- 117个一类村共获批各类资金**4.7亿元**
- 村均**400万元以上**

### 3. 明确评价办法

采用四级评价方式：
1. 村级自评
2. 乡镇初评
3. 县级综合评价
4. 市级抽查复核

每年对"四在农家·和美乡村"建设成效开展综合评价，完成所有基础建设内容、部分提升建设内容且无违反底线任务的村评价为一、二类村。

### 4. 明确激励机制

**市级奖补**：
- 每年预算**5000万元**专项奖补资金
- 对通过评价的一类村和充分激发群众内生动力助力乡村振兴的村予以奖补

**村干部激励**：
- 建立民选村干部基本报酬与乡村振兴工作成效挂钩机制
- 一类村村干部基本报酬提升**10%**
- 连续三年保持一类村的再提高**10%**

## 三、围绕"四个聚焦"强引领

围绕建设农业强、农村美、农民富目标，强化一类村引领带动作用，促进二、三类村稳步提升。

### 1. 聚焦"富在农家"兴产业（产业振兴）

围绕全市**"2+5+N"产业布局**：

| 类型 | 产业 |
|------|------|
| "2"（基础） | 粮油、"菜篮子" |
| "5"（特色） | 茶叶、辣椒、红粱、中药材、生态养殖 |
| "N" | 其他特色产业 |

推动所有行政村因地制宜选定**1-2个特色优势产业**，重点支持一类村提高产业规模化、标准化、市场化、品牌化水平。

**2025年成效**：
- 117个一类村获得产业类发展资金**2.1亿元**，村均**180万元以上**
- 村集体经济平均年收入**47.43万元**
- 农村居民人均可支配收入**2.38万元**

### 2. 聚焦"学在农家"兴人才（人才振兴）

支持农民工、高校毕业生、退役军人创办家庭农场、农民合作社，着力引进四类人才：

- 引一批大学生回乡
- 引一批能人返乡
- 引一批客商到乡
- 引一批专技人才留乡

**成效数据**：
- 2025年以来引进各类人才返乡就业创业**3718人**
- 一、二类村实现全覆盖
- 建立乡村人才库，鼓励创办非遗传人、"乡村掌墨师"等人才工作室
- 全市已认定各类乡村工匠**456人**（国家级1人、省级46人、市级23人、县级386人）

### 3. 聚焦"乐在农家"兴文化（文化振兴）

持续深化陈规陋习治理：
- 滥办酒席
- 低俗婚闹
- 高价彩礼
- 大操大办
- 厚葬薄养

积极推广应用一类村探索形成的乡村治理模式：
- "寨管家"
- "党群直议制"
- "积分制"

大力倡导**"车不过十、礼不过百"**等务实管用做法，带动全市1728个村深入推进移风易俗，培育良好家风、淳朴民风、文明乡风。

### 4. 聚焦"美在农家"兴生态（生态振兴）

以**"两清两改两治理"**为抓手，持续改善农村人居环境：

| 类别 | 内容 |
|------|------|
| 两清 | 清理乱堆乱放、清理残垣断壁 |
| 两改 | 改厕、改圈 |
| 两治理 | 治理生活垃圾、治理生活污水 |

以实施家庭卫生创建行动为抓手，推动**"四净、三规范、两利用"**：

| 类别 | 内容 |
|------|------|
| 四净 | 洁净厕所、洁净厨房、洁净厅室、洁净院落 |
| 三规范 | 规范畜禽圈养、规范物品收纳、规范建设秩序 |
| 两利用 | 垃圾回收再利用、粪污资源化利用 |

**2025年成效对比**：

| 指标 | 一类村 | 二类村 |
|------|--------|--------|
| 卫生厕所普及率 | 95%以上 | 90%以上 |
| 30户以上自然村垃圾收运覆盖率 | 92%以上 | 90%以上 |
| 生活污水治理率 | 77%以上 | 75%以上 |

## 四、围绕"五个共同"增合力（组织振兴）

突出农民主体地位，充分激发群众内生动力，推动实现政府引导不包办、群众主体不旁观、社会参与不缺位的工作格局。

### 1. 共同商定事项

以村党组织为核心，精选小组长、致富带头人、退休老干部等组成组委会，聚焦"乡村振兴怎样干，建设什么内容"等重大事项：

- 定期召开群众大会和组委会会议
- 确保各项决策事项均通过群众集体讨论并形成一致认可方案后实施

### 2. 共同筹措资金

充分发挥财政资金杠杆引领作用：

**资金模式**：
- 政府补助**70%**
- 农户自筹**30%**
- 政府补助不超过**1万元**

通过先建后补、以奖代补、以工代赈等方式，动员群众自筹资金、主动参与农房升级和庭院改造，变政府大包大揽为多方众筹。

### 3. 共同实施项目

探索推广三种建设模式：
- 公共设施政府建
- 到户设施群众建
- 专业领域工匠建

采取先申请、再集资、主动干、带着干、帮助干等方式，引导群众投工投劳。

对入户道路、入院管道、户厕改造、庭院绿化、农房修缮等权属边界清晰的户属设施项目，先选择部分村民代表先行先试，以点带面推动全面实施。

### 4. 共同开展治理

以村党组织为核心，以村民组为单元，以组委会为纽带：

- 健全完善村民自治章程、村规民约
- 聚焦环境卫生整治和乡风文明建设
- 组织群众开展自我管理、自我监督

形成群众的事情群众管、本组的事情本组管、小事不出组、大事先商量的良好氛围。

### 5. 共同享受成果

支持农民合作社、家庭农场和涉农企业等与农户建立紧密型联农带农机制：

推广**"龙头企业+公司+基地+合作社+农户"**模式，形成经营主体与农户在产业链上优势互补、分工合作机制，促进经营主体、集体经济、群众三方共享产业发展成果。

## 经验总结

### 可复制要素

1. **分类建设机制**：一、二、三类村梯次推进，每年动态评估调整
2. **"一图一表一说明"**：通俗易懂的村庄规划图则，群众易于理解和参与
3. **"两清两改两治理"**：环境整治的具体抓手，指标可量化
4. **"五个共同"机制**：政府引导+群众主体，激发内生动力
5. **资金杠杆模式**：政府补助70%+农户自筹30%，多方众筹替代大包大揽

### 适用范围

- 全国各省市乡村建设规划参考
- 村庄分类建设评价体系借鉴
- 群众参与式乡村治理模式推广
- 农村人居环境整治指标参考
