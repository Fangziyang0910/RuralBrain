# 🐛 害虫检测API - 部署使用指南

## 📁 项目结构

```
pest_detection/
├── detector/                    # 核心检测服务
│   ├── app/                    # 应用核心代码
│   │   ├── api/               # API路由
│   │   ├── core/              # 配置管理
│   │   ├── schemas/           # 数据模型
│   │   └── services/          # 业务逻辑
│   ├── models/                # AI模型文件

│   │   └── classes.txt       # 类别列表（必需）
```

## 🚀 方式一：Docker部署（推荐用于生产环境）

### 前置要求
- **Docker Desktop** 已安装并启动
- 至少 4GB 可用内存
- 确保 8001 端口未被占用

### 1. 安装Docker Desktop（如果未安装）
1. 访问 https://www.docker.com/products/docker-desktop
2. 下载并安装 Docker Desktop for Windows
3. 启动 Docker Desktop
4. 确保 Docker 服务正在运行（系统托盘显示 Docker 图标）

### 2. 部署服务

**方式一：使用 PowerShell**
```powershell
# 进入 detector 目录
cd "D:\sourse code\RuralBrain\src\algorithms\pest_detection\detector"

# 构建并启动服务
docker-compose up -d --build
```

**方式二：使用 CMD**
```cmd
cd /d "D:\sourse code\RuralBrain\src\algorithms\pest_detection\detector"
docker-compose up -d --build
```

### 3. 访问服务
- **API文档**: http://localhost:8001/docs
- **健康检查**: http://localhost:8001/health
- **主页**: http://localhost:8001

### 4. 管理服务

```bash
# 查看服务状态
docker-compose ps

# 查看日志
docker-compose logs -f

# 停止服务
docker-compose stop

# 重启服务
docker-compose restart

# 停止并删除容器
docker-compose down
```

## 🧪 API使用示例

### 1. 健康检查
```bash
curl http://localhost:8001/health
```

### 2. 检测害虫（使用 base64 图像）
```bash
curl -X POST "http://localhost:8001/detect" \
     -H "Content-Type: application/json" \
     -d '{"image_base64": "你的base64图像数据"}'
```

### 3. Python测试示例
```python
import requests
import base64

# 健康检查
response = requests.get("http://localhost:8001/health")
print(response.json())

# 检测害虫
with open("test_image.jpg", "rb") as f:
    img_b64 = base64.b64encode(f.read()).decode()

response = requests.post(
    "http://localhost:8001/detect",
    json={"image_base64": img_b64}
)

result = response.json()
if result["success"]:
    print(f"检测到 {len(result['detections'])} 种害虫:")
    for det in result["detections"]:
        print(f"  - {det['name']}: {det['count']}只")
```

### 4. 使用测试脚本
```bash
cd src\algorithms\pest_detection\test
python test.py
```

## 🔧 配置说明

### 修改端口

**Docker方式**：编辑 `detector/docker-compose.yml`
```yaml
services:
  insect-detector:
    ports:
      - "8002:8001"  # 改为其他端口
```

**Python方式**：编辑 `detector/app/core/config.py`
```python
PORT: int = 8002  # 改为其他端口
```

### 环境变量

可以创建 `.env` 文件配置：
```env
HOST=0.0.0.0
PORT=8001
LOG_LEVEL=INFO
```

## 🛠️ 故障排除

### Docker部署问题

**1. Docker服务未启动**
```bash
# 确认Docker Desktop正在运行
# 查看系统托盘是否有Docker图标
```

**2. 端口被占用**
```bash
# 查找占用端口的进程
netstat -ano | findstr :8001

# 修改 docker-compose.yml 使用其他端口
```

**3. 构建失败或网络超时**
```bash
# 清理Docker缓存后重试
docker system prune -a

# 使用国内镜像源（已在Dockerfile中配置）
```

**4. 模型文件缺失**
```bash
# 确保模型文件存在
dir detector\models\best.pt
dir detector\models\classes.txt
```

### Python部署问题

**1. 模块导入错误**
```bash
# 确保从项目根目录运行
cd "D:\sourse code\RuralBrain"

# 使用正确的启动方式
uv run python -m src.algorithms.pest_detection.detector.start_service
```

**2. 依赖缺失**
```bash
# 安装缺失的依赖
uv add fastapi uvicorn pydantic-settings python-multipart
```

**3. 端口被占用**
```bash
# 查找占用端口的进程
netstat -ano | findstr :8001

# 或修改配置文件中的端口
```

**4. 模型加载失败**
- 确保 `detector/models/best.pt` 文件存在且完整
- 检查文件大小是否正常（约 6MB）
