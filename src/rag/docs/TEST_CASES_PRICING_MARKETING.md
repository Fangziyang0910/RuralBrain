## 💰 定价分析测试用例

### 测试用例 1：基础定价分析

**测试问题**：
```
我的有机有机大米成本 3.5 元/斤，品质一等，应该卖多少钱？
```

**预期结果**：
- 提供价格区间（约 ¥4.90 - ¥5.60）
- 说明品质溢价能力
- 给出定价策略建议（溢价定价/差异化定价）
- 提供市场定位建议

---

### 测试用例 2：包含市场数据的定价

**测试问题**：
```
夏季荔枝旺季，供应充足，需求旺盛。成本 2.0 元/斤，品质一等，竞争对手价格 4-6 元，怎么定价？
```

**预期结果**：
- 考虑旺季因素（需求旺盛）
- 分析供应状况
- 参考竞争对手价格
- 给出差异化定价建议

---

### 测试用例 3：竞争导向定价

**测试问题**：
```
散养土鸡蛋，成本 4.0 元/斤，品质优等。市场普通鸡蛋 4-5 元，品牌土鸡蛋 8-12 元。我想走高端路线，怎么定价？
```

**预期结果**：
- 识别高端市场定位
- 分析竞争格局
- 建议溢价定价策略（¥9.0 - ¥12.0）
- 提供品牌差异化建议

---

## 📈 营销策略测试用例

### 测试用例 4：品牌推广

**测试问题**：
```
有机大米想做品牌推广，目标客户是城市中产家庭，注重品质和生活质量。应该怎么营销？
```

**预期结果**：
- 客户画像分析（25-45岁，中高收入，注重健康）
- 产品定位（高端品质定位）
- 推荐渠道（社区团购、电商平台、线下体验）
- 内容营销方向（产品故事、品质认证、用户见证）

---

### 测试用例 5：销量提升（含预算）

**测试问题**：
```
红富士苹果需要提升销量，目标客户是年轻白领，营销预算 5000-10000 元。请给出详细的营销方案，包括预算分配。
```

**预期结果**：
- 预算分配方案（内容30% + 渠道40% + 活动20% + 促销10%）
- 分阶段执行计划
- 具体促销活动
- 预期效果预估

---

### 测试用例 6：客户获取

**测试问题**：
```
有机蔬菜需要获取新客户。目标客户是 25-45 岁、中高收入、一二线城市、注重健康品质的消费者。营销目标是客户获取，请给出获客策略。
```

**预期结果**：
- 准确的客户画像
- 精准的获客策略
- 适合的营销渠道
- 客户留存方案

---

### 测试用例 7：乡村特色营销

**测试问题**：
```
农场直供的土鸡蛋，想做品牌推广，目标客户是城市家庭。请利用乡村特色给出营销建议。
```

**预期结果**：
- 信任营销（口碑传播、可追溯性、农场参观）
- 故事营销（农场故事、农人情怀、乡村生活）
- 体验营销（农场参观、亲子体验、DIY制作）
- 社群营销（微信群、社区团购、社区代理）

## 🔄 综合测试用例

### 测试用例 8：定价+营销综合方案

**测试问题**：
```
有机大米成本 3.5 元/斤，品质一等。面向城市中产家庭做品牌推广，预算 10000 元。请给出完整的定价和营销方案。
```

**预期结果**：
- 定价建议（价格区间、定价策略）
- 营销策略（客户画像、渠道、内容）
- 预算分配
- 整合的上市计划
